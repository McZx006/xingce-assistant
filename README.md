# 行测小助手 · 刷题与错题分析平台

> 面向国考行测备考的**个人离线刷题工具**：把纸质试卷、PDF/Word、粉笔模考数据统一录入，自动判定对错、收录错题、定位薄弱知识点，并用图表追踪单卷与长期进步。数据全部保存在本机浏览器，无需注册、无需服务器。

🔗 **在线使用（免安装）**：<https://mczx006.github.io/xingce-assistant/>

💻 **本地使用（Windows）**：下载本项目后，双击根目录的 **`启动行测小助手.vbs`** 即可。

---

## 一、这个工具有什么用

行测题量大（国考 130~135 题）、时间紧，备考中的错题通常散落在三处：纸质卷面上的勾画、粉笔 App 的模考截图、手抄错题本——刷过的题很难沉淀成可分析的数据。

本工具解决三件事：

1. **录得快**：一张 130 题的试卷，最快约 **2 分钟**完成对错录入（答题卡模式）；题干可后续补录，不影响统计。
2. **知道哪里弱、为什么弱**：自动按知识点计算「薄弱度」排名，按「粗心 / 概念不清 / 方法不熟 / 超时未答」归因，每条结论都标注数据依据。
3. **看得见进步**：单卷错题分布、各模块正确率、长期正确率折线、累计刷题量等图表，累计 3 套试卷后自动生成趋势。

## 二、功能一览

### 1. 五种试卷/题目录入方式（录入页五个标签页）

| 方式 | 适用场景 | 怎么用 | 说明 |
| --- | --- | --- | --- |
| ① 答题卡快速录入 | 对完答案的纸质卷 | 粘贴「你的作答串」+「正确答案串」 | 只录对错数据，130 题约 2 分钟；题干可后补 |
| ② 逐题录入 | 需要题干入库刷题 | 粘贴整道/整卷文本，自动拆分 | 自动识别题干、A-D 选项、答案、解析、知识点；题型/知识点自动沿用上一题；支持 `Ctrl+Enter` 连录 |
| ③ 文件导入（PDF / Word / 图片） | 电子版试卷、试卷截图 | 拖入文件，可多选排队处理 | PDF 优先直读文字层（零误差），扫描页自动转 OCR；`.docx` 直读文本；图片走 OCR 并对低置信度题目高亮提示复核 |
| ④ 粉笔模考导入 | 粉笔 App 模考成绩页 | 复制成绩页文本粘贴 | 自动解析模块得分与逐题对错，错题自动收录 |
| ⑤ 粉笔网页版导入 | fenbi.com 网页版报告 | A. 全选复制报告文本粘贴；或 B. 用配套油猴脚本导出 JSON | 两种方式都可带题干/选项/正确答案/你的答案/解析 |

**答题卡串格式**（录入框标题旁有「?」可展开查看）：

- 每 **5 个字母为一组**，组间空格隔开：`BCADU DABCC BBAUC`
- **未作答用 `U`**（`未`、`?`、`-`、`空` 也兼容）
- 多选题用带题号格式：`12.ABD`；空格只便于核对，不影响解析

### 2. 试卷管理

- 试卷列表按考试日期组织，可查看单卷各模块得分、错题分布、正确率
- 保存试卷后进入「错题确认」：错题已预勾选，可一键收录进错题本
- 文件/逐题录入的题目可追加到已有试卷

### 3. 错题本

- 错题自动预收录（粉笔导入默认开启；答题卡模式保存后手动一键收录）
- 错误类型四类：**粗心 / 概念不清 / 方法不熟 / 超时未答**
- 自动推断规则（均标注「系统推断」，可手动修正）：未作答 → 超时未答；已作答但错 → 方法不熟
- 错题状态流转：待复习 → 复习中 → 已掌握

### 4. 错题刷题

- 按错题本/模块/知识点抽题重练，作答自动写入练习记录，纳入正确率与趋势统计

### 5. 薄弱分析（结论均附数据依据）

- **薄弱知识点 Top 5**，薄弱度公式：`错误率 × log₂(题量+2) × 趋势权重`（log 项抑制小样本，趋势权重反映近 3 次是否在恶化，区间 0.6~1.6）
- 错误类型占比饼图、各模块正确率柱状图（可点击下钻查看该模块错题）
- 自动生成阶段结论文字（最薄弱知识点、主要失分原因、模块差距），可按本周/本月/全部切换

### 6. 统计趋势

- 单卷统计 + 长期趋势：正确率折线（总体/分模块）、累计刷题量、错题知识点占比
- 累计 ≥ 3 套试卷后折线即有趋势参考价值

### 7. 设置

- **知识点库**：预置国考五大模块 34 个常用考点，可自由增删
- **OCR 语言包**：首次使用自动联网下载中英文语言包并缓存；完全离线环境可指定本地 `tessdata` 目录
- **数据备份**：一键导出全部数据为 JSON、从 JSON 恢复、清空数据

## 三、技术栈

| 类别 | 技术 |
| --- | --- |
| 前端框架 | Vue 3（`<script setup>`）+ Vue Router（Hash 模式）+ Vite 5 |
| 本地数据库 | Dexie.js（IndexedDB 封装），离线优先、无后端 |
| 图表 | ECharts 5（按需引入：饼图/柱状图/折线图） |
| PDF 解析 | pdfjs-dist（文字层直读 + 扫描页渲染降级 OCR） |
| Word 解析 | mammoth（.docx 纯文本提取） |
| 图片 OCR | Tesseract.js（chi_sim+eng，Worker 复用、灰度+对比度预处理、行级置信度） |
| 部署 | GitHub Pages + GitHub Actions（推送 main 自动构建发布） |

## 四、快速开始

### 方式一：直接在线使用

打开 <https://mczx006.github.io/xingce-assistant/> 即可，无需安装任何东西。

> 在线版数据保存在当前浏览器中；首次使用图片 OCR 需联网下载语言包。

### 方式二：Windows 本地双击启动（推荐本机长期使用）

**前置要求**：安装 [Node.js](https://nodejs.org/) LTS 版（16 或以上），安装时保持「Add to PATH」勾选。

1. 下载并解压本项目（或 `git clone`）
2. 双击根目录的 **`启动行测小助手.vbs`**
   - 首次启动会自动执行 `npm install`（仅一次，需联网，约 1~3 分钟）
   - 之后自动在后台启动服务并打开浏览器（默认地址 `http://localhost:5173/`）
   - 全程**不弹黑色命令行窗口**；服务已在运行时再次双击会直接打开页面
3. 使用完毕双击 **`停止行测小助手.vbs`** 关闭后台服务

排错：未安装 Node、依赖安装失败、启动超时时均会弹出中文提示；运行日志见 `logs\dev.log`。

### 方式三：开发者手动命令

```bash
npm install      # 安装依赖
npm run dev      # 本地开发，默认 http://localhost:5173/
npm run build    # 产出静态文件到 dist/
npm run preview  # 本地预览构建产物
```

### 粉笔网页版油猴脚本（可选）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 安装项目根目录的 `fenbi-exporter.user.js`
3. 在粉笔网页版报告页点击右下角「导出题目JSON」，得到 `.json` 文件
4. 在本工具「录入试卷 → ⑤ 粉笔网页版 → B. 导入脚本 JSON」中选择该文件

## 五、部署方式

### 已配置：GitHub Pages 自动部署

仓库内置 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)：

- 每次向 `main` 分支 `git push`，GitHub Actions 自动执行 `npm ci → npm run build → 部署 Pages`，约 1 分钟生效
- Pages 发布来源需设为 **Settings → Pages → Source → GitHub Actions**

**部署到你自己的 GitHub 账号（Fork 即用）**：

1. Fork 本仓库
2. 在你的 Fork 中进入 Settings → Pages，Source 选择「GitHub Actions」
3. 在 Actions 页手动运行一次工作流（或随便提交一次触发），完成后站点地址为：
   `https://<你的用户名>.github.io/xingce-assistant/`

### 任意静态托管

`npm run build` 生成的 `dist/` 是纯静态文件，可直接放到 Nginx、Apache、Netlify、Vercel、Cloudflare Pages 等任意静态空间。

> 注意：`vite.config.js` 中 `base: './'` 使用相对路径，可部署在任意子目录下；路由为 Hash 模式（`#/...`），无需服务端配置 history 回退。

- 备份 JSON 包含你的全部备考数据，请妥善保管，勿随意外传

## 九、常见问题

**Q：双击 VBS 没反应？**
A：先确认已安装 Node.js（命令行执行 `node -v` 有版本号）；查看 `logs\dev.log`，或改用「方式三」手动运行 `npm install` 后 `npm run dev`。

**Q：答题卡显示「题数不一致」？**
A：作答串与答案串的题数必须相同。5 个字母一组只是排版习惯，空格多少不影响；检查是否漏抄或多抄。

**Q：OCR 识别不准？**
A：尽量使用清晰、正向、无反光的截图；低置信度题目会被黄色边框标出，逐项修正后再保存。完全离线请在「设置」中配置本地语言包目录。

**Q：PDF 里的题没识别出来？**
A：文字层 PDF 可直接解析；纯扫描 PDF 会自动转 OCR。若排版特殊导致未按题号切块，可改用「② 逐题录入」粘贴文本，或在文件导入结果中手动补全（降级模式）。

**Q：换电脑/换浏览器数据还在吗？**
A：不在。请在旧环境「设置」中导出 JSON，在新环境中导入恢复。

**Q：更新代码后线上网站怎么变？**
A：向 `main` 分支推送后 Actions 自动重新构建发布，无需其他操作。
